# saltcanyon.com

Website for SaltCanyon (Investments, Property Management, Brokerage), Draper, Utah.

- **Edit:** `site/index.html` (single page) and images in `site/img/`.
- **Preview:** from the `site/` folder run `python3 -m http.server 8765`, then open http://localhost:8765.
- **Publish:** push to `main`. Netlify deploys to saltcanyon.com automatically. Each publish uses 15 Netlify credits, so group changes into one push.

If you use Claude Code, it reads `CLAUDE.md` for the design rules and the do-not-touch list. Read it yourself before your first change.
